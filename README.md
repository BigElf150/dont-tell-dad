# Don't Tell Dad — concept site

A scroll-scrubbed film site for [Don't Tell Dad](https://www.instagram.com/donttelldad.sa),
Al Khobar. One continuous 22-second film sits behind the page and is driven frame-by-frame by
scroll position — it never autoplays.

**This is an unofficial concept, not the restaurant's own page.** The photography belongs to
Don't Tell Dad. Hours, dishes and reviews were read from their public Google listing and
Instagram on 14 August 2026 and are not confirmed by the business. No prices are shown because
none have been confirmed.

The page is `noindex`. Built with the `motion-site` workflow.
